O.nails — сайт с общей блокировкой дат
========================================

Теперь дата бронируется на сервере. После успешной заявки она становится занятой
для ВСЕХ посетителей сайта, а не только в браузере одной клиентки.

Как запустить:
1. Установите Node.js 18+.
2. В папке сайта выполните:
   npm install
3. Запустите:
   npm start
4. Откройте:
   http://localhost:3000

Как работает:
- Сайт запрашивает /api/booked-dates и показывает свободность календаря.
- При отправке формы сервер атомарно проверяет, не занята ли дата.
- Если дата свободна, она записывается в data/bookings.json.
- Повторная попытка забронировать ту же дату получает ошибку 409.
- После успешного бронирования открывается Telegram @olkadolka228
  с готовым шаблоном заявки.
- В календаре занятая дата снова не будет доступна для других посетителей.

ВАЖНО ДЛЯ РЕАЛЬНОГО ХОСТИНГА:
Этот вариант рассчитан на сервер/хостинг с постоянным файловым хранилищем.
Если выбранный хостинг не сохраняет data/bookings.json между перезапусками,
нужна база данных (например, Supabase/PostgreSQL). Для нескольких серверных
инстансов также нужна общая БД.

Сейчас блокируется именно календарная ДАТА целиком, независимо от времени.
